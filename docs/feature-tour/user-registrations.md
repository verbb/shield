# User Registrations
Shield can help protect Craft public user registrations against spam.

1. Enable public user registration in Craft, if you haven’t already.
2. Make sure user registration support is enabled in your [Shield Config](../get-started/configuration.md).
3. That is it, future public registrations will be monitored by Shield.

Shield only checks new public registrations. Control Panel user management and existing user profile updates are ignored.
