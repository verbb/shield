<!-- feature-intro -->
Shield uses Akismet to help Craft reject spam before it becomes another moderation task. Protect supported public submissions and user registrations while keeping the forms and content model you already have.
<!-- feature-intro-end -->

<!-- feature-section -->
## Akismet for Craft forms

Send the relevant submission details to Akismet and use its result when processing Contact Form, Guest Entries, or public user registration requests. Each integration stays within the workflow of the plugin that owns the form.

<!-- feature-section-end -->

<!-- feature-section -->
## Configurable spam protection

Configure the Akismet connection and decide which supported submission paths should be checked. Developers can supply the content and request context that makes the decision more useful.
<!-- feature-section-end -->
